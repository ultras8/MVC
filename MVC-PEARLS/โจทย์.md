อาจารย์โมและทีมกำลังพัฒนา PEARLS ให้เหมาะกับคนทุกเพศทุกวัย ทั้งเด็กโต นักศึกษา และผู้สูงอายุ โดยส่วน ของ PEARLS ที่ต้องการพัฒนาเป็นส่วนหน้าการเข้าสู่ระบบ ดังความต้องการด้านล่าง 
ความต้องการของโจทย์ (Requirements) 
นักศึกษาจะต้องเขียนโปรแกรมแบบ MVC (Model-View-Controller) สำหรับ prototype ของโปรแกรมการเข้า สู่ระบบ 
1. เขียนโปรแกรมโดยใช้แนวคิด MVC (Model-View-Controller) Design Pattern หรือแนวคิดอื่น ๆ ที่ คล้ายคลึง โดยใช้ภาษาโปรแกรมใดก็ได้ 
2. ระบบจะต้องสามารถเก็บข้อมูล username และ password ของผู้ใช้เอาไว้ แต่สามารถเก็บอย่างไรก็ได้ (ฐานข้อมูลจำลองสามารถใช้งานได้ทั้งฐานข้อมูลแบบ Relational หรือ NOSQL หรือ JSON File หรือ CSV  File หรือวิธีการอื่น ๆ ขึ้นอยู่กับความถนัด แต่ต้องมีโครงสร้างของข้อมูลครบถ้วนตามที่โจทย์กำหนดให้) โดยนักศึกษาไม่จำเป็นต้องคำนึงถึงหลักความปลอดภัยใด ๆ ของระบบ แต่นักศึกษาจะต้องมีตัวอย่าง  username และ password อยู่ในโปรแกรมอย่างน้อย 5 ตัวอย่าง 
3. โปรแกรมจะต้องสามารถตรวจสอบว่า username และ password ที่ส่งเข้ามาตรงกับข้อมูลที่เก็บไว้หรือไม่  หาก username และ password ตรงกับในฐานข้อมูล ให้คืนค่าว่าเข้าสู่ระบบสำเร็จ หากไม่ตรง ให้คืนค่า ว่าเข้าสู่ระบบล้มเหลว และให้มีการรับค่าเพื่อกลับสู่หน้าจอเข้าสู่ระบบอีกครั้งไม่ว่าจะสำเร็จหรือไม่ก็ตาม 
4. การเข้าสู่ระบบของแต่ละช่วงวัยจะไม่เหมือนกัน ให้แสดงตัวเลือกในหน้าแรกก่อนเข้าสู่ระบบเพื่อแยก ประเภทของผู้ใช้ สำหรับนักศึกษา โปรแกรมจะต้องรับค่า username และ password ผ่านทาง  Command Line สำหรับเด็กโต อาจารย์โมแนะนำว่าควรรับค่าผ่านทาง GUI เพื่อความสะดวกสบาย โดย เด็กจะชอบ GUI ที่มีขนาดเล็ก ตัวอักษรตัวเล็ก ส่วนสำหรับผู้สูงอายุ ทีมได้แนะนำว่าควรรับค่าผ่านทาง GUI
เช่นเดียวกับเด็กโต แต่เนื่องจากทีมได้มองว่า GUI ของผู้สูงอายุควรจะมีขนาดใหญ่ ทั้งช่องรับ username และ  password รวมถึงปุ่ม login และขนาดของตัวอักษร ให้ทำหน้าจอทั้งสามแบบแยกกันให้ชัดเจน การส่งคำตอบสำหรับข้อนี้
